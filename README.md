# C Language Project

## Introduction

C is a general-purpose programming language. It is widely used to learn programming concepts and develop software.

This project demonstrates basic C programming concepts including variables, input/output, conditional statements, loops and arrays.

## Objective

1. To understand the basic structure of a C program.
2. To understand variables and data types.
3. To perform arithmetic operations.
4. To use conditional statements.
5. To understand loops.
6. To understand arrays.
7. To develop basic problem-solving skills.

## Algorithm

1. Start the program.
2. Display the menu.
3. Ask the user to enter a choice.
4. Perform the selected operation.
5. Take the required input.
6. Display the result.
7. Stop the program.

## Topics Covered

- Variables
- Data Types
- Input and Output
- Operators
- If-Else
- Switch Case
- For Loop
- Arrays
